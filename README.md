# WebApp

A collection of web development projects and laboratory assignments.

## Projects

### Backend

The backend part of the application, implemented with JavaScript/Node.js.

### Frontend

The client-side part of the application with HTML, CSS and JavaScript.

### Lab 1

A separate web development laboratory project.

## Technologies

* HTML5
* CSS3
* JavaScript
* Node.js
* npm

## Repository Structure

```text
WebApp/

```

## Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
```

Open `index.html` in a browser or use the configured development environment.

## Purpose

This repository contains educational web development projects created during university coursework and practical assignments.
